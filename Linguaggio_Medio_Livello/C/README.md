# C - Linguaggio di Medio Livello

Questa cartella contiene esercizi C divisi per difficoltà:

- Easy
- Medium
- Hard

## Come eseguire gli esempi

1. Apri un terminale nella root della repository.
2. Compila un file con:

   ```bash
   gcc Linguaggio_Medio_Livello/C/Easy/nome_esercizio.c -o esercizio
   ```

3. Esegui con:

   ```bash
   ./esercizio
   ```

## Come aggiungere nuovi esercizi

1. Scegli il livello corretto (Easy, Medium, Hard).
2. Crea un file `.c` con un nome chiaro.
3. Mantieni l'esempio semplice e focalizzato.
4. Verifica che compili correttamente.
