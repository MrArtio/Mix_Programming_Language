# Python Exercises

This folder contains Python exercises organized by difficulty:

- `Easy/`
- `Medium/`

## How to run Python code

1. Open a terminal in the repository root.
2. Run a file with:

   ```bash
   python Python/Easy/SomeExercise.py
   ```

## How to add new exercises

1. Choose the correct difficulty folder (`Easy`, `Medium`).
2. Create a single `.py` file with a clear, descriptive name.
3. Keep the exercise concise and focused on one topic.
4. Make sure the file runs with the command above.
