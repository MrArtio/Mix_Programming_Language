# JavaScript Exercises

This folder contains JavaScript exercises organized by difficulty:

- `Easy/`
- `Medium/`
- `Hard/`

## How to run JavaScript code

These examples are designed for Node.js.

1. Open a terminal in the repository root.
2. Run a file with:

   ```bash
   node JavaScript/Easy/SomeExercise.js
   ```

## How to add new exercises

1. Choose the correct difficulty folder (`Easy`, `Medium`, `Hard`).
2. Create a single `.js` file with a clear, descriptive name.
3. Keep the exercise concise and focused on one topic.
4. Make sure the file runs with the command above.
