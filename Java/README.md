# Java Exercises

This folder contains Java exercises organized by difficulty:

- `Easy/`
- `Medium/`
- `Hard/`

## How to run Java code

1. Open a terminal in the repository root.
2. Compile a file with:

   ```bash
   javac Java/Easy/SomeExercise.java
   ```

3. Run it with:

   ```bash
   java -cp Java/Easy SomeExercise
   ```

## How to add new exercises

1. Choose the correct difficulty folder (`Easy`, `Medium`, `Hard`).
2. Create a single `.java` file with a clear, descriptive name.
3. Keep the exercise concise and focused on one topic.
4. Make sure the file compiles and runs with the commands above.
