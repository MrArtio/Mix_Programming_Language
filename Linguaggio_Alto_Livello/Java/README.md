# Java - Linguaggio di Alto Livello

Questa cartella contiene esercizi Java divisi per difficoltà:

- Easy
- Medium
- Hard

## Come eseguire gli esempi

1. Apri un terminale nella root della repository.
2. Compila un file con:

   ```bash
   javac Linguaggio_Alto_Livello/Java/Easy/NomeEsercizio.java
   ```

3. Esegui con:

   ```bash
   java -cp Linguaggio_Alto_Livello/Java/Easy NomeEsercizio
   ```

## Come aggiungere nuovi esercizi

1. Scegli il livello corretto (Easy, Medium, Hard).
2. Crea un file `.java` con un nome chiaro.
3. Mantieni l'esempio semplice e focalizzato.
4. Verifica che compili ed esegua correttamente.
