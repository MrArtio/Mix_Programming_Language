# JSON - Esempi ad Alto Livello

Questa cartella contiene esempi JSON divisi per difficoltà:

- Easy
- Medium
- Hard

## Come usare gli esempi

I file JSON possono essere letti con qualsiasi editor o con strumenti da terminale.

```bash
cat Linguaggio_Alto_Livello/Json/Easy/nome_esempio.json
```

Se vuoi validare la sintassi puoi usare `jq`:

```bash
jq . Linguaggio_Alto_Livello/Json/Medium/nome_esempio.json
```

## Come aggiungere nuovi esempi

1. Scegli il livello corretto (Easy, Medium, Hard).
2. Crea un file `.json` con un nome chiaro.
3. Verifica che il JSON sia valido e ben formattato.
