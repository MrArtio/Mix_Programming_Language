# JavaScript - Linguaggio di Alto Livello

Questa cartella contiene esercizi JavaScript divisi per difficoltà:

- Easy
- Medium
- Hard

## Come eseguire gli esempi

Questi esempi usano Node.js.

1. Apri un terminale nella root della repository.
2. Esegui un file con:

   ```bash
   node Linguaggio_Alto_Livello/JavaScript/Easy/nome_esercizio.js
   ```

## Come aggiungere nuovi esercizi

1. Scegli il livello corretto (Easy, Medium, Hard).
2. Crea un file `.js` con un nome chiaro.
3. Mantieni l'esempio semplice e focalizzato.
4. Verifica che lo script funzioni correttamente.
